# §4.3 Pre-Training Evaluations — 차근차근

V4 base 모델의 능력을 어떻게 측정하고 무엇이 좋아졌는지에 대한 정량적 정리.

---

## 1단계: 평가 방법론 — 4 가지 차원

V4 paper 의 base 모델 평가 4 차원 (§4.3.1):

### (a) World Knowledge
- AGIEval, C-Eval, CMMLU, MMLU, MMLU-Redux, MMLU-Pro, MMMLU
- MultiLoKo, Simple-QA verified, SuperGPQA, FACTS Parametric, TriviaQA

### (b) Language Understanding & Reasoning
- BigBench Hard (BBH), DROP, HellaSwag, CLUEWSC, WinoGrande

### (c) Coding & Mathematics
- BigCodeBench, HumanEval (code)
- GSM8K, MATH, MGSM, CMath (math)

### (d) Long Context
- LongBench-V2

→ Base 모델 평가의 의의: **post-training 전 raw capability** 측정. 이게 모델의 "가능성" 의 상한.

---

## 2단계: 비교군 — V3.2-Base vs V4-Flash-Base vs V4-Pro-Base

V4 paper Table 1 의 핵심:

```
V3.2-Base:    37B activated / 671B total
V4-Flash-Base: 13B activated / 284B total  ← 더 작음
V4-Pro-Base:   49B activated / 1.6T total
```

**중요한 비교**: V4-Flash 는 V3.2 보다 **35% 적은 활성 + 42% 적은 총 파라미터**. 그럼에도 거의 모든 항목에서 V3.2 와 동등 또는 우수.

---

## 3단계: 결과 분석 — 강점

### (a) World Knowledge — 압도적 개선

| Benchmark | V3.2 | V4-Flash | V4-Pro | V4-Pro vs V3.2 |
|---|---|---|---|---|
| MMLU | 87.8 | 88.7 | 90.1 | +2.3 |
| MMLU-Pro | 65.5 | 68.3 | **73.5** | +8.0 |
| MMLU-Redux | 87.5 | 89.4 | 90.8 | +3.3 |
| MMMLU | 87.9 | 88.8 | 90.3 | +2.4 |
| C-Eval | 90.4 | 92.1 | 93.1 | +2.7 |
| CMMLU | 88.9 | 90.4 | 90.8 | +1.9 |
| MultiLoKo | 38.7 | 42.2 | **51.1** | **+12.4** |
| Simple-QA verified | 28.3 | 30.1 | **55.2** | **+26.9** |
| SuperGPQA | 45.0 | 46.5 | 53.9 | +8.9 |
| FACTS Parametric | 27.1 | 33.9 | **62.6** | **+35.5** |
| TriviaQA | 83.3 | 82.8 | 85.6 | +2.3 |

→ **FACTS Parametric, Simple-QA verified, MultiLoKo** 에서 **+25~36** pt 의 dramatic 개선. 데이터 강화 (§4.1) 와 모델 scale 의 결합 효과.

### (b) Coding — 혼합 결과

| Benchmark | V3.2 | V4-Flash | V4-Pro | 평가 |
|---|---|---|---|---|
| BigCodeBench | **63.9** | 56.8 | 59.2 | **회귀** |
| HumanEval | 62.8 | 69.5 | **76.8** | +14.0 |

→ HumanEval 은 크게 개선, BigCodeBench 는 V3.2 가 더 나음. 코딩 능력의 차원이 다양함을 보여줌.

### (c) Math — 적당한 개선

| Benchmark | V3.2 | V4-Flash | V4-Pro |
|---|---|---|---|
| GSM8K | 91.1 | 90.8 | 92.6 |
| MATH | 60.5 | 57.4 | **64.5** |
| MGSM | 81.3 | 85.7 | 84.4 |
| CMath | 92.6 | 93.6 | 90.9 |

→ **±2~5pt** 정도. Saturation 근처라 큰 개선 어렵고, **post-training (§5)** 에서 더 큰 향상이 나타남.

### (d) Long-Context — V4 의 핵심 강점

| Benchmark | V3.2 | V4-Flash | V4-Pro |
|---|---|---|---|
| LongBench-V2 | 40.2 | 44.7 | **51.5** |

→ +11.3 pt. **CSA + HCA hybrid + long-document 데이터** 의 결합 효과.

### (e) Language Understanding — Plateau

| Benchmark | V3.2 | V4-Pro |
|---|---|---|
| BBH | 87.6 | 87.5 |
| DROP | 88.2 | 88.7 |
| HellaSwag | 86.4 | 88.0 |
| WinoGrande | 78.9 | 81.5 |

→ ±0~3pt. 이 영역은 모델 능력이 이미 상한 근처라 base 학습으로 큰 개선 어려움.

---

## 4단계: V4-Flash 의 특별한 의미

V4-Flash 가 **V3.2 의 35% 활성 파라미터로 거의 모든 항목 동등 이상** 인 점이 의미하는 바:

### 효율성의 정량 검증
- 활성 13B / 총 284B 의 모델이 활성 37B / 총 671B 의 V3.2 와 동급 + 일부 영역 우수
- → "**V4 의 architecture/data 개선이 단순 scaling up 효과가 아니다**"
- 즉, mHC, hybrid attention, hash routing 등 §2 변경의 누적 효과

### Open model ecosystem 영향
- V4-Flash 는 **dual GPU 클러스터** 으로 효율 추론 가능
- → frontier-급 능력의 lower-cost deployment

---

## 5단계: V4-Pro-Base 의 위치

V4-Pro-Base 가 **DeepSeek 시리즈 사상 최강 base 모델**:
> "DeepSeek-V4-Pro-Base further extends this advantage to set a new performance standard among DeepSeek foundation models, achieving comprehensive superiority across reasoning, coding, long-context, and world knowledge tasks."

- World knowledge 의 +25~36pt 가 가장 dramatic
- Long-context 가 차별화 포인트
- Code/math 는 plateau 영역이라 post-training 으로 추가 향상

---

## 6단계: Base 평가가 보여주는 §4 의 종합 효과

§4 의 모든 변경이 어떻게 base score 에 반영되는지:

| §4 영역 | 영향 받는 차원 | Δ |
|---|---|---|
| §4.1 web filtering | World knowledge cleaning | knowledge 점수 ↑ |
| §4.1 multilingual 확장 | MultiLoKo, multilingual 평가 | +12.4 |
| §4.1 long-document curation | LongBench-V2 | +11.3 |
| §4.1 agentic data (mid-train) | code, agent | post-training 효과 |
| §4.2 학습 안정화 | 모든 task | 학습 완주 |
| §4.2 1M curriculum | LongBench-V2 | 안정적 1M |
| §2 architecture (CSA/HCA, mHC) | long-context, scaling efficiency | +11.3 LongBench, V4-Flash 효율 |

→ **§2 architecture + §4 data/training 의 결합** 이 base 능력의 base.

---

## 7단계: Frontier 까지의 거리 (Base 단계)

### Base 모델 비교 (자료 한계로 정성적)

V4-Pro-Base 의 base 능력:
- 오픈모델 중 최강 (Qwen3.5-Max, Kimi K2.5/K2.6 base 모델보다 우수, 추정)
- Closed model base (GPT-5/5.2 base, Claude Opus 4.5/4.6 base) 와는 직접 비교 불가 (closed 의 base 미공개)

→ V4-Pro-Base 는 **"오픈모델로 도달 가능한 base capability 의 frontier"** 로 볼 수 있음.

---

## 정리 — §4.3 한눈에 보기

| 차원 | V3.2 → V4-Pro 개선 | 개선 폭 | 주요 driver |
|---|---|---|---|
| World Knowledge | +2~36pt | **dramatic** | data 강화 |
| MultiLoKo | +12.4 | dramatic | multilingual 확장 |
| FACTS | +35.5 | **dramatic** | scientific paper |
| HumanEval | +14.0 | large | scale + agentic data |
| BigCodeBench | -4.7 | **회귀** | 원인 불명 |
| Math | +2~5pt | small | saturation |
| Lang Understanding | ~0pt | plateau | saturation |
| LongBench-V2 | +11.3 | large | long-doc + hybrid attn |

**핵심 통찰**:
1. **World knowledge 와 long-context 가 V4 의 primary 강점** — 데이터·아키텍처 둘 다 이쪽 방향
2. **FACTS Parametric +35.5** 는 SimpleQA-Verified +26.9 와 함께 **factual recall 개선** 의 강력한 증거
3. **V4-Flash 가 V3.2 와 동급** = architecture 개선이 단순 scaling 이상의 효과
4. **Math 와 language understanding 은 saturation** — base 단계에서 추가 개선 어렵고, post-training (§5) 의 영역
5. **BigCodeBench 회귀**는 unaddressed — V4 paper 가 명시적 분석 없음
6. Base 평가가 §2 architecture + §4 data/training 의 통합 효과를 보여주는 정량적 검증
