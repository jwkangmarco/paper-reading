# 메트릭 계산 예시 상세 풀이 (샘플 5개, 3-class, G=8)

> [추론 기반 분류 모델 학습 가이드](./reasoning_classification_training_guide.md#35-메트릭-계산-예시-샘플-5개-3-class-g8) 3.5절의 계산 과정을 단계별로 설명한다.

```
learnable_frac = 40%   zero_adv_frac ≈ 67%   pass@1 = 52.5%   MV@∞ = 60%   sharpen_gap = 7.5pt
```

## 설정
- **3-class**: 라벨은 Perfect / Passable / Bad 세 개
- **G=8**: GRPO가 한 샘플에 대해 rollout 8개를 생성
- **보상은 이진값**: 정답이면 1, 오답이면 0
- 각 샘플에서 모델이 정답을 낼 확률 p만 정해 두고 지표를 손으로 계산한다

---

## 1. 샘플 5개의 의미

| 샘플 | 모델 출력 분포 (정답 / 오답A / 오답B) | 직관적 의미 |
|---|---|---|
| 1 | 1.0 / 0 / 0 | 항상 맞힘 |
| 2 | 1.0 / 0 / 0 | 항상 맞힘 |
| 3 | 0.5 / 0.25 / 0.25 | 절반만 맞히지만, 정답이 가장 자주 나옴 |
| 4 | 0.125 / (나머지 0.875를 오답 두 개가 나눔) | 가끔 맞히고, 대부분 틀림 |
| 5 | 0 / … | 한 번도 못 맞힘 |

---

## 2. 지표별 계산

### ① learnable_frac = 40%
정의: `0 < p < 1`인 샘플의 비율. 맞을 때도 있고 틀릴 때도 있어야 학습 신호가 생긴다.

| 샘플 | p | 0<p<1? |
|---|---|---|
| 1 | 1.0 | ✗ (항상 맞힘) |
| 2 | 1.0 | ✗ |
| 3 | 0.5 | ✓ |
| 4 | 0.125 | ✓ |
| 5 | 0 | ✗ (항상 틀림) |

→ 2/5 = **40%**

### ② zero_adv_frac ≈ 67%
GRPO의 advantage는 `보상 − 그룹 평균 보상`이다. **rollout 8개의 보상이 모두 같으면**(전부 맞음 또는 전부 틀림) advantage가 모두 0이 되어 그 샘플에서는 gradient가 나오지 않는다. 그 확률은 다음과 같다.

```
P(8개 모두 정답) + P(8개 모두 오답) = p^8 + (1−p)^8
```

| 샘플 | p | p^8 | (1−p)^8 | 합 |
|---|---|---|---|---|
| 1 | 1.0 | 1 | 0 | **1.000** |
| 2 | 1.0 | 1 | 0 | **1.000** |
| 3 | 0.5 | 1/256 | 1/256 | **0.0078** (≈0.008) |
| 4 | 0.125 | ≈0.00000006 | 0.875^8 ≈ 0.3436 | **0.3436** (≈0.34) |
| 5 | 0 | 0 | 1 | **1.000** |

```
평균 = (1 + 1 + 0.0078 + 0.3436 + 1) / 5 = 3.3514 / 5 ≈ 0.670 → 67%
```
- 0.875^8은 0.875² = 0.7656 → ⁴ = 0.5862 → ⁸ = 0.3436 순서로 계산한다.
- 샘플 3의 오답이 0.25/0.25로 나뉘는 것은 여기서 영향이 없다. 보상이 이진값이라 오답끼리는 모두 0이기 때문이다.
- **해석**: rollout 계산의 약 2/3가 gradient 0으로 낭비된다. 샘플 4도 learnable하지만, 3번에 1번꼴(34%)로는 8개가 모두 틀려 신호가 나오지 않는다.

### ③ pass@1 = 52.5%
정의: 한 번 생성했을 때 맞힐 확률, 즉 p의 평균이다.
```
(1.0 + 1.0 + 0.5 + 0.125 + 0) / 5 = 2.625 / 5 = 0.525 → 52.5%
```

### ④ MV@∞ = 60%
무한히 생성해 다수결을 내면 **출력 분포의 최빈값(mode)** 이 답이 된다. 최빈값이 정답인 샘플의 비율이 MV@∞다.

| 샘플 | 최빈값 | 정답? | 이유 |
|---|---|---|---|
| 1 | 정답 (1.0) | ✓ | |
| 2 | 정답 (1.0) | ✓ | |
| 3 | 정답 (0.5 > 0.25, 0.25) | ✓ | 절반만 맞혀도 오답이 둘로 나뉘어 정답이 1위 |
| 4 | 오답 | ✗ | 남은 0.875를 오답 두 개가 어떻게 나눠도 적어도 하나는 ≥ 0.4375 > 0.125 |
| 5 | 오답 | ✗ | |

→ 3/5 = **60%**

샘플 3이 3-class 설정의 핵심이다. 이진 분류라면 p=0.5는 동률이지만, 오답이 두 라벨로 흩어지면 정답이 다수결에서 이긴다.

### ⑤ sharpen_gap = 7.5pt
```
sharpen_gap = MV@∞ − pass@1 = 60 − 52.5 = 7.5pt
```
**의미**: 모델이 새로 배우는 것 없이 **"자기가 가장 자주 내는 답을 항상 내도록" 분포만 날카로워지면** 정확도가 얼마나 변하는지를 나타낸다. 샘플별로 나눠 보면 이 값이 어디서 오는지 보인다.

| 샘플 | sharpening 전 p | 후 | 변화 |
|---|---|---|---|
| 1, 2 | 1.0 | 1.0 | 0 |
| 3 | 0.5 | 1.0 | **+0.5** |
| 4 | 0.125 | 0 | **−0.125** (최빈값이 오답이라 오히려 손해) |
| 5 | 0 | 0 | 0 |

```
(+0.5 − 0.125) / 5 = 0.075 → 7.5pt
```

---

## 3. 표의 "해석" 열이 말하는 것

- **샘플 3 — GRPO가 가장 잘 고치는 유형**: 보상이 모두 같을 확률이 0.8%뿐이라 거의 항상 학습 신호가 나온다. 최빈값도 이미 정답이라 sharpening이 그대로 정답 쪽으로 간다.
- **샘플 4 — DPO나 guidance가 필요**: 신호는 66% 확률로 나온다. 하지만 8개 중 평균 1개만 맞아 신호가 약하고, 모델의 "주관"이 오답 쪽에 있다. RL이 실제로는 sharpening 쪽으로 기울면 오히려 0으로 떨어질 위험이 있다. 그래서 오답을 직접 밀어내는 DPO나, 정답 힌트를 주는 guidance가 필요하다.
- **샘플 1, 2, 5 — RL로는 개선 불가**: 1·2는 이미 다 맞혀서 배울 것이 없다. 5는 정답이 한 번도 나오지 않아 보상 신호가 아예 없으므로 라벨 검수나 지식 주입으로 접근해야 한다.

---

## 4. 주의: MV@8과 MV@∞

가이드 3.1절은 sharpen_gap을 **`MV@8 − pass@1`** 로 정의하지만, 이 예시는 **MV@∞** 로 계산한다. 유한한 k=8에서는 샘플 3도 다수결이 가끔 오답으로 갈 수 있어서 MV@8은 60%보다 약간 낮게 나온다.
